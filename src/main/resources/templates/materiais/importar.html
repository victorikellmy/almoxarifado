2. Como o arquivo deve estar estruturado

A primeira linha da planilha precisa conter os títulos das colunas. A ordem não importa e colunas extras são ignoradas — o sistema se orienta pelos títulos. Se o arquivo tiver várias abas, apenas a primeira é lida.

3. Regras que a importação aplica
SKU é gerado pelo sistema

Deixe a coluna sku vazia para materiais novos: o código sai no formato AREA-SUB-00001 e vira a identidade física do item na etiqueta. Preencher um SKU inexistente resulta em erro na linha, e o SKU de um material já cadastrado nunca é alterado.

Reenviar o arquivo não duplica

Um material é considerado o mesmo quando tem o mesmo nome dentro da mesma subcategoria. Nesse caso a linha atualiza o cadastro em vez de criar um item repetido.

Campo em branco não apaga dado

Numa atualização, colunas deixadas em branco preservam o que já está cadastrado. Para zerar um valor, informe 0 explicitamente.

Estoque com histórico

No modo Somar, cada quantidade importada vira uma movimentação de entrada (RN05) e fica rastreável. No modo Definir o saldo é sobrescrito sem movimentação — use apenas para carga inicial ou correção de inventário.

Uma linha ruim não derruba o lote

Cada linha é gravada isoladamente. Se a linha 37 tiver um valor inválido, ela aparece em vermelho no relatório e as demais entram normalmente.

Números e acentos

Valores aceitam 1.234,56 ou 1234.56. Quantidades devem ser inteiras. CSV salvo pelo Excel em ANSI é lido corretamente — acentos não viram símbolos estranhos.
